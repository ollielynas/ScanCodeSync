Ollie Lynas - Sync Based Media Sorting

This software allows the sorting of media generated during production.
This is made easy via the mobile interface. Simply scan the interface using each of your cameras, or record a short audio clip using each of your microphones.
This allows the devices to be synchronized in post. This can then be used to sort the files based on metadata generated by the Director and operators.
Files will be sorted based on Project, Scene, Take, Operator Name and Date.
